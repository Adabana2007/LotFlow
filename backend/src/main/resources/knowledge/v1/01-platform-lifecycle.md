# LotFlow 平台定位与商品生命周期

## 平台定位

LotFlow 面向普通用户，允许普通人把二手物品或有故事的旧物通过拍卖出售。平台不是只服务收藏级奢侈品的高端拍卖行，也不允许卖家把商品直接创建为秒杀商品或商城商品。

每件商品都必须先经过发布和审核，再进入拍卖渠道。同一件商品在任意时刻只能处于拍卖、秒杀、商城中的一个销售渠道，不能同时在多个渠道出售。

## 单件库存

一场拍卖只对应一件商品和一个库存单元。同款有多件时必须拆成多个库存单元。秒杀和商城同样按单件交易，不提供购物车、SKU 或多件合并购买。

## 商品生命周期

商品通常依次经历：

1. 草稿。
2. 待审核。
3. 已通过、待修改或已驳回。
4. 待开拍。
5. 拍卖中。
6. 成交后进入付款、发货、确认收货和售后阶段。
7. 拍卖流拍后进入自动降级或卖家决策。
8. 秒杀未售出后按授权进入商城。
9. 商城到期未售出后退回卖家库存。

状态只能通过对应的业务动作改变，普通用户不能直接把商品修改成任意状态。

## 渠道降级链路

卖家预先授权的完整链路是：

```text
拍卖 -> 24 小时秒杀 -> 30 天商城
```

卖家未授权自动降级时，拍卖流拍后进入 24 小时卖家决策，卖家可以选择重新拍卖、进入秒杀或退回库存。超时未决定时，商品退回库存，平台不能默认替卖家低价出售。

## 价格约束

所有渠道价格必须满足：

```text
0 < 商城价 <= 秒杀价 <= 起拍价
```

起拍价就是拍卖最低成交价，不设置隐藏保留价。自动降级不能突破卖家预先设置的最低售价。

## 事实来源与用户边界

商品、拍卖、订单、钱包和审核状态以平台数据库记录为准。平台助手不能自行推断成交、扣款、退款或审核已经发生，只能通过用户有权访问的只读查询确认当前用户的数据。
